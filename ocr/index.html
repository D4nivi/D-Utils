OCR (Extracción de texto)

Reconocimiento óptico de caracteres en cliente mediante Tesseract WebAssembly. Extrae texto de imágenes, documentos y capturas de forma 100% privada sin subir archivos a ningún servidor.

Aviso de seguridad del navegador: Estás abriendo la herramienta desde file://. Por seguridad interna, los navegadores impiden que los Web Workers carguen WebAssembly y ficheros locales directamente. Para ejecutar el OCR, abre esta página a través de un servidor web local (por ejemplo con npx serve, la extensión Live Server de VS Code o python -m http.server) o directamente en GitHub Pages.
